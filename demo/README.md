# Demo scripts

Text you can paste into **/send** and read aloud for voice notes. Record **your own voice, with consent**. Kinproof does not generate or clone anyone's voice, and the demo should never use a real person's voice without their permission.

| File | Scenario | Expected outcome |
|---|---|---|
| [01-scam-voice-note.md](01-scam-voice-note.md) | Cloned-voice "accident" scam | Held, Chidi taps "No", money returned |
| [02-genuine-emergency.md](02-genuine-emergency.md) | Real request to Chidi's verified PayPal | Chidi taps "Yes", captured in seconds |
| [03-lost-phone-redirect.md](03-lost-phone-redirect.md) | "Lost my phone" + hospital | Redirect: pay St. Luke's directly |
| [04-celebrity-giveaway.md](04-celebrity-giveaway.md) | Fake public-figure prize fee | High risk, held, cooling-off, unverified payee |

Setup: sign in as **Ada** in one browser window and **Chidi** in a second (a private window works). Ada is the sender; Chidi is the real person who gets the confirmation card.
